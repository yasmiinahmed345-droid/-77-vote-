# 🗳️ -77- Discord Vote Bot

Discord bot leh vote system casri ah — server kasta data-giisa gooni ah.

## Commands

| Command | Sharaxaad | Cidda isticmaasha |
|---|---|---|
| `/vote create` | Vote cusub samee | Everyone |
| `/joojivote` | Vote-ka socda jooji | Admin only |
| `/setvotes @user amount` | User votes set gare | Admin only |
| `/voteusers` | Voters list muuji | Admin only |

## Setup

1. `npm install`
2. `.env` file samee:
```
DISCORD_TOKEN=your_bot_token_here
DISCORD_CLIENT_ID=your_application_id_here
```
3. `npm start`
